### Selected Work

#### 01 / [trashwhere](https://github.com/Nearrr1/trashwhere)

> **Educational Waste-Classification Web Platform**  
> _Stack: Next.js (App Router), TypeScript, Tailwind CSS, Google Gemini Vision API, MongoDB Atlas, Vitest_

- Built an educational web application for high-school students in Vietnam to classify waste items via camera capture or photo upload.
- Integrated Gemini Vision model to identify 6 canonical waste categories with confidence scoring, material breakdown, and localized Vietnamese disposal guidelines.
- Features server-side AI processing, NextAuth v5 authentication, cloud scan history persistence, and test coverage using Vitest.

#### 02 / [web-warehouse](https://github.com/Nearrr1/web-warehouse)

> **E-Commerce Bookstore Client & Inventory Workspace**  
> _Stack: React, Vite, TypeScript, Redux Toolkit, TanStack React Query, Tailwind CSS_

- Implemented the frontend for an end-to-end bookstore e-commerce system featuring customer catalog browsing, cart management, and inventory flows.
- Structured application state with Redux Toolkit and managed asynchronous server state and caching policies with React Query.
- Enforced strict TypeScript contracts and component modularity across complex dashboard views.

#### 03 / [warehouse-svc](https://github.com/Nearrr1/warehouse-svc)

> **Distributed Warehouse & Inventory Backend Service**  
> _Stack: Java 21, Spring Boot 3, Spring Data JPA, Spring Security, Spring Cloud Gateway, Docker_

- Developed an inventory management microservice part of a decoupled distributed architecture alongside `api-gateway` and `notification-svc`.
- Engineered domain data models with Spring Data JPA, secured endpoints with Spring Security, and registered services under Spring Cloud Eureka.
- Containerized for reproducible deployment with Docker and standard Maven build lifecycle.
